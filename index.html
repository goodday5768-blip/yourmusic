YourMusic 너의 음악

내가 가진 음악 파일을 앨범·아티스트별로 정리해 듣는 아이폰·아이패드 플레이어

지원개인정보 처리방침예시 곡

무엇을 하나요

  • MP3·M4A·AAC·WAV·AIFF·FLAC 등 기기에 넣은 음악 파일을 재생합니다.
  • 파일 속 정보(제목·아티스트·앨범·트랙 번호·앨범 아트·가사)를 읽어 앨범·아티스트·노래로 정리합니다.
  • 플레이리스트, 다음에 재생·나중에 재생, 임의 재생·반복, 가사 보기, 잠금 화면·제어 센터 조작, AirPlay를 지원합니다.
  • 스트리밍·구독·계정이 없습니다. 음악 파일과 목록은 모두 이 기기 안에만 있습니다.

음악 넣는 법 · 지원

  1. 앱의 「음악 가져오기」(＋) → 파일 앱·iCloud Drive에서 파일이나 폴더를 고릅니다.
  2. 맥 Finder에서 기기를 고르고 「파일」 탭의 「너의 음악」에 끌어다 놓습니다.
  3. 다른 앱의 음악 파일을 「공유 → 너의 음악」으로 보냅니다.
  4. 파일 앱 「나의 iPhone › 너의 음악」 폴더에 넣으면 앱을 열 때 저절로 들어옵니다.
